# Основные функции
1)	Ввод данных о клиенте через графический интерфейс.
Пользователь открывает десктопное приложение и заполняет форму с характеристиками клиента, соответствующими признакам из датасета IBM Telco. Для удобства ввода категориальные признаки (пол, тип интернет-услуги, тип контракта, способ оплаты и др.) представлены в виде выпадаю-щих списков с предопределёнными значениями, а числовые признаки (стаж, ежемесячный платёж, общая сумма) вводятся в соответствующие поля. Про-граммное решение автоматически проверяет корректность введённых дан-ных: все обязательные поля должны быть заполнены, числовые значения должны быть неотрицательными и соответствовать ожидаемому формату. При обнаружении ошибок пользователь получает понятное сообщение с ука-занием конкретного поля для исправления.
2)	Получение прогноза оттока клиента.
Получение прогноза оттока клиента. После успешного ввода данных пользователь нажимает кнопку "Получить прогноз". Программное решение загружает предварительно обученную лучшую модель (выбирается автома-тически по метрике F1-score среди логистической регрессии, случайного леса и градиентного бустинга), обрабатывает введённые параметры (масштабиро-вание числовых признаков, One-Hot Encoding категориальных) и выдаёт ре-зультат в наглядном формате: вероятность оттока в процентах, бинарный прогноз ("Клиент уйдёт" / "Клиент останется") и качественную оценку уровня риска ("Низкий", "Средний", "Высокий") с цветовой индикацией (зелёный — низкий риск, красный — высокий риск). Дополнительно на основе модели случайного леса отображается диаграмма важности признаков, которая по-казывает, какие характеристики клиента в наибольшей степени повлияли на прогноз. Это позволяет пользователю не только получить ответ, но и понять его причины для принятия обоснованного управленческого решения.
3)	Сохранение результатов прогнозирования в отчёт.
После получения прогноза пользователь может сохранить результат для последующего анализа или документирования. Программное решение предоставляет кнопку "Сохранить отчёт", при нажатии на которую текущий прогноз (дата, параметры клиента, вероятность оттока, бинарный прогноз, уровень риска) записывается в CSV файл.
